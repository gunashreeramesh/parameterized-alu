# Parameterized ALU Design using Verilog HDL
## Project Overview
This project implements a parameterized Arithmetic Logic Unit (ALU) using Verilog HDL.
The ALU is designed using configurable parameters for data width and opcode width, making the design reusable for different hardware configurations.
The project covers the RTL design, functional verification, simulation, waveform analysis, and synthesis using Cadence Genus.

## Project Objectives
- Design a parameterized ALU using synthesizable Verilog HDL.
- Verify the functional behavior using a Verilog testbench.
- Analyze simulation waveforms.
- Synthesize the RTL using Cadence Genus.
- Analyze area, power, and timing.
- Understand the RTL-to-gate-level VLSI design flow.
